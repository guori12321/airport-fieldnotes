# Airport Fieldnotes · 陌生机场到访指南

给首次到访美国通航机场的飞行员准备的中文桌面研究。第一批：[Reid-Hillview（KRHV）](airports/KRHV.md) · [San Martin（E16）](airports/E16.md)。

## 第一次去一个机场，准备哪些资料？

以白天、轻型固定翼、VFR 为起点。机场页记录有来源的背景资料，每次飞行另做当日简报。

| 准备环节 | 这次飞行需要回答的问题 |
|---|---|
| 从哪边来 | 在当前 sectional/TAC 上画出实际来向、地形、邻近机场和分层空域边界；按路线及高度核对 Approach 扇区，预留改跑道或改降的方案。 |
| 怎么认场 | 从来向找一两个可辨认地标；视频标明日期（未知则留空）、跑道、飞行阶段、关键时间点。标出容易认错的平行跑道、滑行道、道路或邻近机场。 |
| 怎么加入航线 | 逐个跑道端列左右航线、适用机种与航线高度（明确 MSL/AGL）、塔台开关时段、非塔台活动；分清历史视频中的飞法、当地公布建议与当天 ATC 指令。 |
| 噪音与特殊活动 | 区分离场、横风边、下风边、训练时段；标出学校、居民区、跳伞区，以及资料来源或与旧版本的冲突。 |
| 跑道与性能 | 场高、长宽、坡度、表面、移位入口、公布的可用距离、灯光/PAPI；用当日气温、风、重量和本机 POH 核算性能，另考虑湿跑道或关闭部分。 |
| 障碍在哪里 | 按跑道端写明种类、相对高度、沿中心线距离、横向偏移、参考点；另查航路地形、塔线、临时吊机与复飞方向。单个控制障碍不构成完整障碍清单。 |
| 和谁通话 | 天气、Approach、Tower 或 CTAF、Ground、Departure 分栏；注明运行时间、跑道或扇区。频率清单不是自动换频顺序。 |
| 着陆之后 | 在现行机场图上从可能的出口找到目的机坪；标出穿越跑道、热点、访客停机、燃油类型、开放时间及地面出入口。 |
| 当天刷新 | 查 NOTAM/TFR、天气趋势及侧风、跑道/滑行道/灯光可用性、活动空域、油量和备选机场。资料过期或目标跑道变化就重新简报。 |

数据核对日：2026-11-22。基础版次见机场页。入口：[FAA Chart Supplement](https://www.faa.gov/air_traffic/flight_info/aeronav/digital_products/dafd/) · [FAA 航图及机场图](https://www.faa.gov/air_traffic/flight_info/aeronav/digital_products/) · [FAA NOTAM Search](https://notams.aim.faa.gov/notamSearch/) · [Aviation Weather Center](https://aviationweather.gov/)。

社区补充可提 Issue 或 PR：附机场、跑道端、资料链接和日期；视频请加时间点及画面能确认的地标。请勿从旧视频抄录现行频率或推断许可。首批仅为机场熟悉研究，不包含实时简报。
